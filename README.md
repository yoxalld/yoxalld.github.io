# dustinyoxall.github.io

This is the source code for my portfolio site hosted on GitHub Pages. The site showcases projects and provides information about my work as a developer and IT professional.

## Project Structure

- `_config.yml`: Configuration settings for the site, including theme, title, and description.
- `_data/navigation.yml`: Navigation structure for the site, linking to Home and Projects pages.
- `_projects/sample-project.md`: Details of a sample project, including metadata and relevant links or images.
- `_layouts/project.html`: Layout for individual project pages, structuring project details.
- `index.md`: Home page of the portfolio site, featuring an introduction and links to the Projects page.
- `projects.md`: Projects page listing all projects with links to individual project pages.

## Setup Instructions

1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Install any necessary dependencies (if applicable).
4. Run a local server to view the site (e.g., using Jekyll or another static site generator).
5. Customize the content in the `_projects` directory to add your own projects.
